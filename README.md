## 🧠 Tentang Saya

Halo! Saya **Rendika Angesti** — seorang **Full-Stack Developer** dan **Backend Engineer** yang berfokus pada pengembangan aplikasi web modern, performa tinggi, dan aman. Melalui **Djoeragan Cyber**, saya merancang serta membangun solusi perangkat lunak *custom* siap produksi.

Prinsip kerja saya berpusat pada konsistensi siklus sistem: **Desain Skema Basis Data → Arsitektur Backend/API → Antarmuka Frontend → Audit Keamanan → Perataan Pengujian → Eksekusi Deployment**.

Dengan latar belakang kesadaran keamanan siber (*cybersecurity awareness*), setiap sistem yang saya kembangkan dibangun dengan prinsip **Defensive Engineering**: mengutamakan validasi input, manajemen otentikasi yang solid, pembatasan hak akses (*authorization*), serta mitigasi *edge cases* secara terukur.
